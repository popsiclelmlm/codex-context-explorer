# Demonstration screenshots

These images were reviewed for use in the project README. They show the actual built browser UI with a synthetic transport and entirely synthetic project names, session content, paths, token counts and fees. They do not contain real account data, email addresses or local filesystem paths. Each includes a visible DEMO DATA watermark and has no embedded text or EXIF metadata.

- hover-en-dark.png — English dark theme, highlighting the Skills share, 1280 × 1440.

These are browser-report illustrations, not evidence of native-host validation or measured performance. The app's MIT license applies to this project-authored demonstration imagery; upstream icon notices remain in the project notices.
